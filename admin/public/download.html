How to install

  1. Tap Download above. The file is fairly large, so use Wi-Fi or make sure you have enough bundles.
  2. When it finishes, tap the notification or open Files → Downloads and tap the DukaSmart file.
  3. If your phone says it can't install apps from this source, tap Settings, turn on Allow from this source, then go back.
  4. If Play Protect shows a warning, tap More details → Install anyway. This appears because DukaSmart is not on Play Store yet.
  5. Open DukaSmart, tap Create account.

What you get

  • Know who owes you deni, and remind them by SMS
  • Count your stock and scan barcodes

  • Your records are backed up safely online
